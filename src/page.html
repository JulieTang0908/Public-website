这三种图分别回答什么？

观测后的组成概率：给定一条模拟的连续读数 z，比较所有合法组成。每条 N 曲线显示这些候选的后验概率。切换长杆读数与噪声，可看信息丢失后有多少种解释。

均匀先验的组成概率：没有读入图片，所有合法组成等概率。因为 x 与组成一一对应，这张图本来就平；不会因为 N 增大自动变成钟形。

原始特征的边际分布：先让组成变化，再让对象随机摆放，观察 F0 或 F2 的分布。这才是最初 P(F|N) 的问题。F0 不是组成的唯一编号；多个组成可能有同一个 F0。正态参考只是对照，不参与推断。

组合指标 x：如何从前六个特征恢复组成？

短粒子数记为 a，长杆数记为 b。前六个特征为 F0=ΣMᵢ、F1=ΣiMᵢ、F2=ΣMᵢMᵢ₊₁、F3=非零段数、F4=各段长度平方和、F5=值为2的格数。在理想 [2,2] 模型中，F0 与 F5 已足够恢复组成。

F0=a+4b，F5=2b ⇒ a=F0−2F5，b=F5/2
x=b(N+2−b)+a，x=0,…,KN−1
KN=(⌊N/2⌋+1)(N+1−⌊N/2⌋)

先按 b 从少到多分组，再按 a 排序。已知 N 和整数 x 可以反解 a、b；鼠标悬停会显示它们。x 只编码组成数量，不区分全部摆放，其距离没有物理意义，编号上的峰形也依赖排序。

归一化编号为 x/(K−1)；编号的 Z 坐标使用均匀编号的均值 (K−1)/2、标准差 √((K²−1)/12)。这两种坐标都保留原编号用于反解。含噪或二值观测不能直接硬算 F5，所以由后验给所有候选赋概率。

原始模型、均匀先验和概率公式

A=[1] 占一格；B=[2,2] 占相邻两格；空格为0。不重叠、不要求填满、没有半根杆。合法组成 a≥0、b≥0、a+2b≤N。这里严格使用原来的“合法数量组合等概率”，没有换成固定粒子概率或覆盖率先验。

P(a,b|N)=1/KN
R(N,a,b)=C(N−b,b) C(N−2b,a)
P(F=f|N)=Σa,b P(F=f|a,b,N)/KN
P(X=x|N)=1/KN（所有合法编号）

R 是给定组成的合法摆放数。每种组成内，各摆放等概率；不能把所有摆放直接等权混合，否则会改变组成先验。

zᵢ=mᵢ+εᵢ，εᵢ∼Normal(0,σ²)
La,b(z)= [ΣM∈合法摆放(a,b) exp(−||z−M||²/(2σ²))]/R(N,a,b)
P(a,b|z,N)=La,b(z) / Σa′,b′La′,b′(z)

高斯测量误差不等于“组成服从高斯分布”。在 [1,1] 模式中用占据读数代替 M。每个组成的似然对全部合法摆放求平均；共用的高斯常数在后验中抵消。

这些曲线是怎样逐个算出来的？

组成后验：首次打开使用600条已核验的参考曲线；修改 σ 或重新模拟后，用本机后台计算逐个重算 N=1～100。全部使用对数空间的加权铺放递推，没有用几个间隔 N 插补。

Q0,0,0=1，非法状态为0；eᵢ(v)=exp[−(zᵢ−v)²/(2σ²)]
Qi,a,b=eᵢ(0)Qi−1,a,b+eᵢ(1)Qi−1,a−1,b+eᵢ₋₁(c)eᵢ(c)Qi−2,a,b−1
c=2（类型可读）或1（二值）；La,b=QN,a,b/R(N,a,b)

特征 F0：每个组成直接给出 F0=a+4b，全部 N 都精确加权。特征 F2：N≤8 枚举全部组成与摆放并正确加权；N=9～100 每个 N 独立进行30,000次分层抽样，先均匀抽组成，再均匀抽该组成的摆放。页面会标出蒙特卡洛结果。

显示方式：三维图保留所选 N 范围内的全部候选或特征格点；相邻顶点之间的连接仅作显示。热图用201个共同 x 区间聚合概率，不作 KDE。单独切片保留完整数据；聚焦范围可以关闭。

每条离散曲线满足 Σp=1。密度选项显示 p/Δx；归一化特征坐标为 F/N，Z 标准化使用该 N 的混合分布均值与标准差。三维连接部分下的体积不是离散概率归一化依据。log显示只把低于10⁻¹²的高度截在−12，原始概率不变。

为什么不强行把原始混合分布画成正态？

固定组成和混合组成是不同问题。F0 在固定组成后甚至是常数，它的边际分布变化完全来自组成混合。Z 标准化只改变坐标，不会自动把分布变成正态。

在均匀数量组合先验下，F0/N 的大 N 连续极限是 [0,2] 上以1为顶点的三角形：f(t)=t（0≤t≤1），f(t)=2−t（1≤t≤2）。页面显示的是有限 N 的离散结果。不能把一个指定的钟形当作实验结论；可以在切片中打开正态区间概率，直接比较。

F2 的 N=1 分布退化在0，因此 Z 标准化未定义；在 Z 图中明确略去这个退化切片，原始/归一化图仍保留它。
