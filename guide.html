一维随机排列模型：N–x–p 概率图说明

配套交互页面：同目录下的 index.html；本说明随独立网站一起分发。

本文用于解释页面里的参数、曲面的含义，以及向导师汇报时可以使用的说法。当前结果来自一维合成数据。

1. 研究问题和模型

我们考虑一个长度为 N 个格子的一维视野。空格读数为 0，短粒子 A 占一格，理想读数为 [1]；长杆 B 占相邻两格，理想读数为 [2,2]。对象不重叠，不要求填满视野，只计入完整长杆。

记短粒子数为 a，长杆数为 b，合法组成满足：

$$a\geq0,\quad b\geq0,\quad a+2b\leq N.$$

每种合法数量组合采用相同先验概率；给定组成后，再让该组成的合法摆放等概率出现。这里“组成等概率”与“把所有摆放直接等权混合”不同。

项目包含两个需要区分的问题：

  • 特征分布：组成和摆放随机变化时，某个观测特征 F 的分布 $P(F\mid N)$ 如何随视野长度变化？
  • 组成推断：看到一条有噪声的观测后，每种组成有多大可能，即 $P(a,b\mid z,N)$？

页面默认显示第二个问题；“原始特征的边际分布”选项展示第一个问题。

2. 三个坐标轴分别是什么

参数含义读图时需要注意
N视野格数包含 1～100 的每个整数，不是粒子总数。
a、b短粒子数、长杆数它们是我们希望推断的组成。
x将组成 (a,b) 编成的整数编号已知 N 后可以反解组成，但编号差值没有物理距离意义。
p当前观测下，该组成的后验概率每个 N 的所有候选概率相加为 1。

合法组成总数为：

$$K_N=(\lfloor N/2\rfloor+1)(N+1-\lfloor N/2\rfloor).$$

组成按 b 从小到大分组，组内按 a 排序，编号为：

$$x=b(N+2-b)+a,\qquad x=0,1,\ldots,K_N-1.$$

页面默认用归一化坐标：

$$u=\frac{x}{K_N-1}.$$

u=0.5 不表示长杆占 50%。不同 N 下，同一个 u 也未必代表同一种组成。 这个坐标是为了把数量不同的候选放到共同的展示范围。鼠标悬停可查看具体 a、b。

3. 概率、密度和其他控制项

页面选项含义
概率 p单个组成所分得的概率，数值在 0～1 之间。
区间密度 p/Δx概率除以显示坐标上的格点间距。归一化组成坐标下，Δx=1/(K_N−1)。密度可以大于 1，不能读成百分比。
测量噪声 σ每格加性高斯读数误差的标准差；σ=0.5 不是“50% 错误率”。
[2,2] 类型可读短粒子与长杆的理想读数不同。
[1,1] 只看占据长杆两格也读为 1，容易与相邻短粒子混淆。
原始值 / 归一化 / Z 标准化改变横坐标的表示；Z 标准化不会自动产生正态分布。
log₁₀ 显示用对数高度看较小概率；显示低值有截断，原始概率不变。
二维热图将同一 N 的概率聚合到共同显示区间，以颜色表示区间概率或密度。

这里的 Δx 指当前显示坐标的间距，不一定是整数编号的间距。如果选择原始编号，间距就是 1。

4. 整个曲面表示什么

固定一个 N，可以得到一条“候选组成—概率”曲线。把 N=1、2、…、100 的曲线沿 N 轴排在一起，再连接成曲面，就得到这张图。

  • 峰较高的位置：当前观测更支持这些候选组成。
  • 多个峰：存在多组较合理的解释，需要保留不确定性。
  • 概率集中在少数候选：在当前模型与观测下，组成约束较强。
  • 概率分散：观测难以排除很多候选。

组成编号的排序会影响峰的形状。 相邻编号不一定代表相近的物理组成，因此峰宽只能辅助读图；定量比较不确定性，应进一步看可信候选集合、熵或 a、b 各自的边际分布。

页面中橙线是选中的 N，细线是其他整数 N 的曲线。三角面只用于连接和显示，没有额外计算小数 N 的实验；曲面下的总体积也不是归一化依据。应检查每个 N 切片的概率和是否为 1。

目前各 N 使用相关的合成场景与共用噪声前缀。因此这张曲面是演示，不能仅凭它断言“视野增大后识别准确率必然提高”。这一结论需要独立重复实验。

5. 图是怎么算出来的

观测模型为：

$$z_i=m_i+\varepsilon_i,\qquad \varepsilon_i\sim\mathcal N(0,\sigma^2).$$

对于一种候选组成 (a,b)，我们对其所有合法摆放计算观测似然，并取平均。合法摆放数是：

$$R(N,a,b)=\binom{N-b}{b}\binom{N-2b}{a}.$$

省略所有候选共用的高斯常数后：

$$L_{a,b}(z)=\frac{1}{R(N,a,b)}\sum_{M\in\mathcal M_{N,a,b}}\exp\!\left[-\frac{\|z-M\|^2}{2\sigma^2}\right].$$

其中 $\mathcal M_{N,a,b}$ 是该组成的合法摆放集合。在二值模式下，用占据读数替代上式中的 M。结合均匀组成先验，得到：

$$P(a,b\mid z,N)=\frac{L_{a,b}(z)}{\sum_{(a',b')\text{合法}}L_{a',b'}(z)}.$$

实际计算使用动态规划求摆放之和，不必逐张列出所有大视野图像。每个整数 N 都单独计算；不是只计算少数 N 再补出中间曲线。

例如，默认 [2,2]、σ=0.5、N=50 时，共有 676 种合法组成。最高概率候选约为 (a,b)=(17,9)，概率约 5.16%；合成真值为 (17,8)。这说明最高概率只是当前最受支持的候选，不能保证等于真值。在归一化坐标下，该峰的密度约 34.8，仍不代表 3480% 的概率。

6. “六个特征”和“正态曲线”应怎样理解

前六个特征包括总读数 F0、位置加权和 F1、相邻乘积 F2、非零段数 F3、段长度平方和 F4、值为 2 的格数 F5。

在理想、无噪声的 [2,2] 模型下：

$$F_0=a+4b,\quad F_5=2b\quad\Rightarrow\quad a=F_0-2F_5,\ b=F_5/2.$$

因此理想条件下，仅 F0、F5 就能确定数量组成。但当前含噪后验计算使用的是完整逐格连续读数，尚未证明只保留六个特征后也能达到相同推断效果。x 是候选组成的编码，不是已经验证过的含噪充分特征。

原项目的特征边际分布为：

$$P(F=f\mid N)=\frac{1}{K_N}\sum_{(a,b)\text{合法}}P(F=f\mid a,b,N).$$

页面的 F0 分布全部精确计算；F2 在 N≤8 时精确枚举，其余每个 N 使用 30,000 次按组成先验抽样的模拟。

离散实验可以与正态近似比较：用正态分布落入每个整数格点对应区间的概率，与离散概率比较；但是否接近正态需要检验。在当前均匀组成先验下，F0/N 的大 N 极限是三角分布，不能强行要求它成为正态。高斯测量噪声也不意味着组成后验必须是高斯形状。

7. 向导师介绍时可以这样说

我们先建立了一个一维模型：短粒子占一格，长杆占两格，各种合法数量组合采用均匀先验。看到模拟的含噪读数后，我们对每种组成的所有合法摆放求平均似然，再计算组成的后验概率。 为了把 N=1～100 的结果放在同一张图里，我们把短粒子数和长杆数编码成一个可逆编号 x。固定 N 是一条组成概率曲线，多条曲线排列起来就是这个曲面。它主要展示观测能把组成约束到什么程度，以及类型信息丢失或噪声存在时还有多少种可能解释。 这张图目前是合成数据下的组成推断演示。原项目的特征边际分布 P(F|N) 在另一个视图中单独展示。接下来需要分别检验：哪些特征分布可以用正态近似，以及仅保留有限特征时，组成推断会损失多少信息。当前还不能把这张图当成真实照片识别已经完成的证据。
